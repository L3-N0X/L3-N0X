### Currently Building

- **[goatty](https://github.com/goatty-dev/goatty)** — A fast GPU-accelerated terminal emulator written in Rust and GPUI. Everything in the UI has mouse support, every setting has a GUI, and built-in plugins work with a single click. It aims to ship with the best default experience out of the box while staying easy to tweak visually, and connects directly to remote hosts without slowing down the terminal.
